## Owner decisions (2026-11-23)

Recorded verbatim from the maintainer:

> "Stick to the default free service and drop all the configuration options. If the user wants custom translation services, he should switch to the desktop Elanero."

What this means for the design:

- The web uses only the default free service, **MyMemory**. No Azure, no LibreTranslate, no service picker.
- **No configuration of any kind**: no API keys (no entry, no persistence, no in-memory key store), no Azure region, no MyMemory email.
- **Withdrawn:** Test connection, the service settings panel, per-service keys, `translate/keys.ts`, the `credentials` RPC field, and the questions on key persistence and the email (old questions 3, 4 and 5).
- Custom services are a desktop feature. The web points to the desktop app for them, in one sentence in the guide and one in Preferences.
- Consent still applies: the user agrees to MyMemory's notice before the first request, and a changed notice asks again. Only the selected text is sent, straight from the browser's engine worker to MyMemory, with no relay and nothing in the background.

## 2. The service on the web

| Service | Endpoint | Needs | Sent |
|---|---|---|---|
| MyMemory (Translated.net) | `https://api.mymemory.translated.net/get` (GET) | nothing | `q` (a chunk of the selected text) and `langpair=src\|tgt`; never `de=` |

MyMemory **cannot detect the source language** (`detects_source = False`), so the From picker has no "Detect language" entry (§8). Its limits stay the client's: `max_text_chars` 2,000, `max_request_bytes` 500, so at most 5 requests per call (§6).

Not on the web: DeepL, Azure, LibreTranslate and any custom endpoint. S2 narrows S1 to match (§15): `WEB_SERVICES = ("mymemory",)`, the CSP, `TRANSLATION_ORIGINS` and `WEB_ENDPOINT_ORIGINS` list MyMemory's origin only, and `translation.test` goes. Shrinking the CSP is the outer guarantee: even a bug in the gate cannot reach Azure or LibreTranslate from the web build.

## 3. Where the request runs: an allow-listed XHR in the engine worker

Unchanged from the first design (option A) and built in S1: the engine worker keeps a private `XMLHttpRequest` captured before lockdown, exposes it to Python only through `elanero_net`, and the gate refuses unless the URL is `https:`, its origin is in `TRANSLATION_ORIGINS`, the call is synchronous, and the gate is **armed**. The worker-server arms it only while it runs a method in `TRANSLATION_METHODS` and disarms it in `finally`.

Changes in S2: `TRANSLATION_ORIGINS` becomes `['https://api.mymemory.translated.net']` and `TRANSLATION_METHODS` becomes `{'translation.translate'}`. Time bounds stay: 10 s per request, 30 s per call (`_Deadline`), reported as `TRANSLATION_OFFLINE` with the partial text.

Cancel in the bubble (Esc, click outside, new selection) does not abort a running request; the main thread drops the late reply (request id). It cannot run on, because the gate disarms when the call returns.

## 4. RPC

After S2:

```text
translation.info      {}  ->  {services: [{id: "mymemory", name, privacyUrl, detectsSource, maxChars}],
                               languages: {mymemory: [{code, name}, ...]}}
translation.translate {text, source, target}  ->  {text, detected: string|null, service}
```

- `info` keeps its list shape (one entry), so the generated types and S1 tests change little; `needsKey` is removed.
- `translate` loses `service` and `credentials`. Python always builds the MyMemory translator with an empty email and the web opener. `source` is required (a code from `info`); a missing or unknown code is `INVALID_ARGS` before any request.
- `translation.test`, `check_connection`, `TranslationCredentials`, `TranslationTestParams`, `NEEDS_KEY` and `WEB_LIBRETRANSLATE_URL` are deleted.
- Error mapping is unchanged (`OfflineError`→`TRANSLATION_OFFLINE`, `QuotaError`→`_QUOTA`, `AuthError`→`_AUTH`, `ConfigError`→`_CONFIG`, `TooLongError`→`_TOO_LONG`, `SameLanguageError`→`_SAME_LANGUAGE`, else `_SERVICE`), with `details.partial`. The handler logs the character count only, never the text.
- `translation.translate` enters the method table in **S3**, with the bubble.

## 5. Settings and their storage

| Setting | Stored where | Why |
|---|---|---|
| Translation on/off (`translationEnabled`) | `elanero.prefs` | Off by default. |
| Default target language (`translationTarget`, `''` = same as the app) | `elanero.prefs` | As on the desktop. |
| Last From language (`translationLastSource`) | `elanero.prefs` | MyMemory needs a source; remembers the user's last choice. |
| Consent record (`translationConsent`) | `elanero.prefs` | §7. |

Nothing else: no service, no key, no region, no email. Nothing about translation is secret, so nothing is kept outside `elanero.prefs`, and Clear all local data removes all of it.

## 6. Request shape and size limit

- The main thread sends the raw selected text. Python cleans it and enforces MyMemory's 2,000 characters (`TRANSLATION_TOO_LONG`).
- The main thread refuses raw text over **40,000 characters** before sending (same code and message), so a select-all never crosses to the worker. Python checks the same cap.
- Chunking and the wire format are the client's own, unchanged: `GET /get?q=…&langpair=src|tgt`, at most 500 bytes of text per request.
- Only the selected text is sent: no file name, page number, document language, email or other text. The document's `/Lang`, if MyMemory lists it, only preselects From on the main thread.

## 7. Consent flow and record

1. The user selects text and chooses **Translate** (selection toolbar or palette, §8), or turns on the switch in Preferences ▸ Translation.
2. If translation is off, or `translationConsent` does not match `{service: 'mymemory', version: NOTICE_VERSION}`, the **consent notice** opens (react-aria `Dialog`) **before anything is sent**:
   - Title: "Translate selected text with MyMemory?"
   - Body: "Only the text you select is sent, from your browser straight to MyMemory (Translated.net). It sees the text and your IP address. Nothing is sent until you choose Translate, and nothing is sent in the background. You can turn this off in Preferences ▸ Translation."
   - Buttons: the primary button (**Translate** from the bubble, **Turn on** from Preferences), **Cancel**, and a **Privacy policy** link to MyMemory's policy (`privacyUrl` from `info`) in a new tab, through the existing link-confirm path; the notice stays open.
3. The primary button writes `translationEnabled: true` and `translationConsent: {service: 'mymemory', version: NOTICE_VERSION, at: <ISO date>}`; from the bubble it then sends. **Cancel** writes nothing and sends nothing.
4. Raising `NOTICE_VERSION` (a changed notice) asks again. The `service` field is kept so a future change of service also asks again. Turning translation off clears the record.

The record is local only and is removed by Clear all local data (it lives under `elanero.`).

## 8. The bubble

- **Entry points:** a small **selection toolbar** next to a non-empty text selection, with **Copy** and **Translate**, and the palette entry "Translate selection" (`translate-selection`, enabled only with a selection). No new shortcut; the palette is the keyboard path (question 1).
- **Placement:** anchored to the selection's last line rectangle, with the comment toolbar's placement helper; flips above when there is no room below; a bottom sheet in the narrow layout.
- **Contents:** From picker (MyMemory's languages, **no Detect entry**), a swap button, To picker, the translation in a read-only selectable region with `aria-live="polite"`, "Translated by MyMemory", **Copy** and **Add as note**. While waiting: a spinner and "Translating…". Changing From or To runs it again (the cache answers repeats).
- **Defaults, as the desktop's `translate_bubble.py`:** From is the first of the document's `/Lang`, `translationLastSource`, `en` that MyMemory lists; To is `translationTarget`, else the UI language, else English, else the first language that differs from From. Choosing From writes `translationLastSource`.
- **Copy** uses `text/copy.ts` and the "Copied" toast.
- **Add as note** runs `annotations.highlight_text` (§9) with the selection's per-page rectangles and the translation as the note, one undo step, author = `authorName`. Disabled when the document is read-only or busy, or the selection changed since the bubble opened.
- **Closing:** Esc, a click outside, a new selection, a scroll or zoom, or a tab switch; a later reply is dropped.
- **Accessibility:** non-modal `role="dialog"` with a label; focus moves in on open and back to the page on close; all strings via `t()`.

## 9. Add as note

Done in S1: `annotations.highlight_text` in `actions/comment_tools.py` makes one highlight per page with a quad per line, the note on the first, capped at 2,000 rectangles, one undo step, with its round-trip test. S3 only calls it.

## 10. Errors and offline

| Case | What the user sees | Sent? |
|---|---|---|
| `navigator.onLine === false` | `error.TRANSLATION_OFFLINE`, with **Try again** | No |
| Network failure, CORS refusal, timeout | `error.TRANSLATION_OFFLINE` (the page cannot tell CORS from offline) | Attempted |
| 429 / quota reply | `error.TRANSLATION_QUOTA` | Yes |
| 401/403 | `error.TRANSLATION_AUTH`, reworded in S2: "The translation service refused the request. Try again later." | Yes |
| No From language | Cannot happen from the UI; `error.TRANSLATION_CONFIG`, reworded: "Choose the language of the selected text." | No |
| Too long | `error.TRANSLATION_TOO_LONG` | No |
| Same language | `error.TRANSLATION_SAME_LANGUAGE` | No |
| Part done | The partial translation, plus "Only part of the selection was translated." | Partly |
| Engine restarted mid-call | The existing restart toast; the bubble closes | Unknown |

No error string mentions a key or Preferences settings. The service worker ignores cross-origin requests, so replies are never cached offline (a test pins it).

## 16. Tests

No test touches the real network. Python tests inject a fake opener; Vitest replaces the RPC with fakes; the gate tests use a fake XHR class.

- **Python (`test_webapi_translate.py`, runs under Pyodide):** MyMemory through a fake opener (URL has `q` and `langpair`, never `de`); a missing or unlisted `source` refused before any request; extra fields (`service`, `credentials`) refused; each error class to its code; `details.partial`; the deadline stops between chunks; caplog never contains the text; `info` returns exactly one service with MyMemory's `max_text_chars`; `WEB_ENDPOINT_ORIGINS` equals `TRANSLATION_ORIGINS` and the CSP's `connect-src` minus `'self'`, all MyMemory only.
- **Vitest `translationNet.test.ts`:** refused when disarmed, for Azure, LibreTranslate, look-alike hosts, user-info URLs and `http:`; MyMemory allowed when armed; disarms after a throw; only `translation.translate` arms.
- **Vitest `translate/*.test.tsx`:** no RPC before consent; Cancel sends and records nothing; the primary button records `{service, version, at}`; a raised `NOTICE_VERSION` asks again; turning off clears the record; offline sends nothing; each error code shows its string; partial text shown; From/To defaults follow §8 and From never offers Detect; Copy writes the clipboard; Add as note calls `annotations.highlight_text` and is disabled after the selection changes; a late reply is dropped; over 40,000 characters refused before RPC.
- **Vitest Preferences:** no service picker, key, region, email or Test connection field; the desktop sentence is present; the prefs store holds only the four translation fields.
- **e2e (W8.1, optional):** `page.route` fulfils MyMemory's host; not a required check.

## 17. Risks

| Risk | Mitigation |
|---|---|
| A network path in the worker that parses untrusted PDFs | Captured XHR never on `globalThis`; one origin, identical to the CSP; armed only during `translation.translate`. The CSP is the outer wall. W8.6 reviews it. |
| A slow service freezes rendering | 10 s per request, 30 s per call, at most 5 requests; 40,000-character main-thread cap. |
| MyMemory keeps submitted text in its translation memory | Stated through its privacy link in the notice; the guide says not to translate confidential text and points to the desktop for other services. |
| MyMemory's anonymous daily limit is low and cannot be raised on the web (no email) | `TRANSLATION_QUOTA` says to try later; the guide mentions the limit and the desktop. |
| No language detection | From preselects from `/Lang` and the last choice; the guide explains it. |
| MyMemory's CORS policy changes (W0.3 was a snapshot) | Shows as offline; the `web-cors` workflow can re-probe. |
| Synchronous XHR deprecation | Allowed in workers in all three engines today (W2.4); revisit if a browser warns. |
